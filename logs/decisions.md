# Decisions Log

### Decision 1 : Modifying Hardware choice and the project's name
**Date:** February 13th, 2026
**Description:**
The Microcontroller of the system (PIC16F877A) is replaced with a 32 bit ARM Cortex-M0 based MCU (STM32F103C8T6)
Therefore, The name of the project will be changed from "Trainer's PIC"  to "ARM Flex".
**Reasons:**
- Better performance per cost
- Better support
- Essential skill for my career
